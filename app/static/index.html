Agentic Research & Evidence Synthesis Engine

Retrieval + LangGraph agents over 1,585 NLP papers (QASPER). Browse every answer the system gave on its evaluation sets: each claim cites a passage (click [E#]), QASPER's gold passages are marked, and an LLM judge rated every citation, the faithfulness and the correctness.

These are the saved answers from the evaluation runs (no live model calls on this free page). The live Gradio app, all code and the report are on GitHub.

Data: QASPER (Dasigi et al., 2021), CC BY 4.0. Models: BAAI bge-small-en-v1.5, BAAI bge-reranker-v2-m3, OpenAI gpt-oss-120b (agent) and gpt-oss-20b (judge) via Groq; Google Gemini (second judge). Answers can be wrong: the judge verdicts and gold marks are there so you can check.
